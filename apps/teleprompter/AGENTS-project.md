# Eyeline recording project

This folder contains script.md, project.json, takes/, footage/, edit-plan.json and optionally edit/. Treat recordings and take metadata as original sources. Never replace them with an assembled video.

Each take has audio.wav and take.json with attempts, script lines, roughCut, utterances, flubs and microphone health data. Browser recognition timings are approximate. The root edit-plan.json is a cross-take script draft, not the source-linked editor plan in edit/plan.json.

Keep candidate edits separate from the active plan. Review full audible words and joins, not only transcript spellings. Ask the owner before replacing manual work. Track decisions in NOTES.md and leave complete source handles available. The public repository's docs/formats.md describes the data contracts.
