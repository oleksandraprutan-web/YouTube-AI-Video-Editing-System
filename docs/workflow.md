# Workflow from recording to editor

1. **Prepare.** Run `python3 tools/init_project.py PROJECT_FOLDER`. Customize `preferences.json` and the skill placeholders. Put the script in `01-recording/script.md`. Record decisions and file paths in NOTES.md.
2. **Record.** Open/create the project in Eyeline teleprompter. For the scaffold, set `EYELINE_DATA` to a parent containing a `Projects` folder and put `01-recording` there, or record in the prompter's normal project folder and copy the entire recording folder into the scaffold after recording. Do not move a recording while the prompter is saving. Record camera video separately in `01-camera/`.
3. **Ingest.** Transcribe every camera-backed take with `ingest_words.py`, measure camera sync with `ingest_sync.py`, and create source-timeline proxies with `ingest_proxy.py`. Register camera filenames/sizes in `edit/footage.json`. See formats.md and cutting.md. Exclude audio-only practice takes from video selection unless deliberately producing audio-only material.
4. **Candidate cut.** An agent proposes source-linked intervals in `edit/plan.candidate.json`, or uses the experimental assembler. Audition alternative readings. Review off-script speech explicitly. Record unresolved issues with take names and seconds.
5. **Review.** A human approves loading the candidate. Back up any active plan first; copy the approved candidate to `edit/plan.json` with all editor tabs closed. Never automatically replace a manual edit. Open the editor, link camera footage, play the full cut, inspect joins, and export WAV/video. Transcribe the actual assembled WAV. Read the whole transcript and listen to flagged boundaries before approving.
6. **Design.** After cut approval, prepare the visual brief and board-by-board content. Use Claude Design or another HTML design tool with the generic prompt. Save HTML and assets to `04-boards/`. Review the boards at video size.
7. **Animation.** After board approval, use final-cut word timings to populate `05-animation/timeline.json`. Keep motion deterministic, preserve the approved voice, and render the silent board track. Inspect first/middle/last states and the full review.
8. **Editor handoff.** Put the cut MP4, approved WAV, board track, timing manifest, captions, source-linked cut JSON, and notes together. Assemble in your NLE using the WAV as the only narration track. Keep original camera links in Eyeline for revisions. Review the final video and publish only with permission.

Each stage's role, inputs, outputs, and approval requirement is also declared in `config/workflow.json`. The agent roles are model-agnostic Markdown instructions; they do not launch a hosted agent service.
