# Customize the placeholder skills

The public skills are blank creative contracts, not copies or redactions of a private skill pack. Each says `PLACEHOLDER — NOT CONFIGURED` and includes fields you fill in. There is no bundled personal voice imitation, channel research, proprietary design system, or production reference library.

1. Copy a placeholder to `.local/skills/` (ignored by Git).
2. Define its inputs, expected outputs, examples, decisions it may make, and when it must ask you.
3. Set audience, tone, typography, color, pacing, motion and review rules that belong to your project.
4. Tell your agent which customized file to load; automatic skill installation is intentionally not performed.
5. Try it on a synthetic/sample project and review the result before using valuable recordings.

This is instruction tuning, not model-weight fine-tuning. Publish your own customized files only after checking their contents and source rights. The generic role documents in agents/ govern handoffs; your project preferences govern creative choices.
