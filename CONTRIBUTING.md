# Contributing

Keep changes focused and include reproduction/validation details. Never commit real recordings, credentials, private skills, personal projects, cache files or model weights. Use the synthetic demo for bug reports. The visual media in docs/media is an explicit owner-approved allowlist.

Before a PR, run the commands in docs/setup.md. New editing features need source-mapping tests and a non-destructive migration plan. Report untested OS/camera/browser assumptions. Creative skill contributions should be generic templates with clear ownership; do not paste another creator's private voice or design instructions.
