# Filled design brief: comparing measurements

Status: synthetic example. All numbers below are invented for layout demonstration.
Audience: someone learning how to read a fair comparison.
Takeaway: consistent units and a shared baseline make differences interpretable.
Canvas: 1920 × 1080. Camera: lower-right 576 × 432, inset 64 px.
Style: neutral chart with direct labels, no product colors or logos.

## Board 01 — Chart
- File: `03-chart.html`
- Headline: Compare values on the same scale.
- Sample values: A=40, B=65, C=85 units per sample.
- Scale: 0–100, ticks every 25; bar width = value / 100 × 800 px.
- Labels: Sample A / Sample B / Sample C. Subtitle: Illustrative data.
- Direction: higher means more units; it does not mean better.
- Example narration: “Each bar uses the same scale, so the lengths can be compared directly.”
- Replace the numbers, units, source, axis, bar widths, and accessible description together for real use.

- Display a source note. Record a full citation in the brief.
