# Filled design brief: a review process

Status: fictional example, not an approved production brief.
Audience: someone learning to make a repeatable process.
Takeaway: inputs become useful outputs through an explicit review decision.
Canvas: 1920 × 1080. Camera: lower-right 576 × 432, inset 64 px.
Style: neutral paper, charcoal text, system sans-serif, no logos or promotions.

## Board 01 — Process
- File: `01-process.html`
- Example narration: “We collect the material, choose what supports the idea, and deliver something we can check.”
- On-screen text: Collect / Choose / Deliver.
- Diagram: three equal cards with left-to-right arrows. Every arrow is a transformation, not a decorative connector.
- Visual purpose: give the viewer a map of the whole process.

## Board 02 — Layers
- File: `05-layers.html`
- Example narration: “Keep the source below the decisions so the final result can always be revised.”
- On-screen text: Source layer / Decision layer / Output.
- Diagram: three stacked responsibilities. Read bottom to top.
- Visual purpose: explain why the source remains available.

## Board 03 — Recap
- File: `08-recap.html`
- Example narration: “Keep the source, check the decision, and make the next step clear.”
- On-screen text: the same three actions, one sentence each.
- Visual purpose: turn the explanation into a checklist.
