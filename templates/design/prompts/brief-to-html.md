# Prompt: reviewed brief → HTML starter boards

Build the boards in the attached reviewed brief. Use the selected unbranded starter HTML files as editable layout examples. The reference library may include branded or unrelated content; it supplies layout ideas only. Do not copy its assets, names, logos, links, distinctive brand styling, episode claims, embedded metadata, or private instructions.

Deliver one self-contained HTML file per board and an index linking to them. Inline CSS and SVG, use system fonts, and make no external requests. Use real editable text. Set the canvas to the brief's size and preserve the camera safe area. Keep the headline static and match the exact approved copy. Make charts mathematically consistent, label units, and add accessible descriptions. Include a visible source note for claims.

Start with static layouts and a callable window.seek(seconds) that leaves their state stable, for compatibility with the local renderer. Do not add autonomous animation, timers, music, sound effects, zooms, or background removal. Motion is a separate approved step.

Before returning: open every board, check overflow at full resolution and readability at quarter size, verify no content enters the camera region, and inspect HTML/CSS/comments/links for residual branding. List missing evidence instead of inventing it. Return filenames, preview images, and unresolved issues for review. Do not publish.
