# Библиотека хуков, графики и переходов (из референсов автора)

Источник: референс-ролик TikTok (@socialcontentking, «3 viral hooks», англ.) + вставка «edited 100% with Claude Code». Берём **приёмы**, не контент: тексты пишем по-польски под тему ролика, музыку из референса не используем.

## Хуки (первые 1–3 секунды)
| Код | Хук | Формула | Пример для адвокатов (PL) | Пример для автосервиса (PL) |
|---|---|---|---|---|
| H1 | **Pattern interrupt** | Начать с фразы, которая непонятна/шокирует, пока её не объяснили | «Nie składaj pozwu, zanim tego nie zrobisz.» | «Nie wymieniaj oleju, zanim tego nie zobaczysz.» |
| H2 | **Personal callout** | Первое слово — «Ty/Ciebie», прямое обращение к зрителю и его ошибке | «Tracisz alimenty, jeśli nie wiesz tego.» | «Niszczysz silnik, jeśli robisz to co rano.» |
| H3 | **Unexpected number** | Конкретная цифра/вопрос с цифрой | «2500 zł alimentów — skąd sąd bierze tę kwotę?» | «8 000 km czy 15 000 km — kiedy naprawdę wymienić olej?» |
| H4 | **Список-обещание** | «3 rzeczy…», цифры 1-2-3 появляются карточками | «3 błędy, które przegrywają sprawę o opiekę» | «3 dźwięki, których nie wolno ignorować» |

Правило: «Specifics beat vague» — конкретика (цифры, сроки, суммы) всегда сильнее общих слов. Хук формулируем только из того, что человек реально говорит в ролике; если хук нужно переснять — предложить текст автору, не монтировать выдуманную речь.

## Графические вставки
| Код | Элемент | Как выглядит |
|---|---|---|
| G1 | **Карточки-номера 1/2/3** | Маленькие вертикальные карточки (скруглённые, белая обводка, лёгкое свечение) с кадром-превью внутри и крупной белой цифрой; в хуке — веер из 3 карточек вокруг головы, при «Number one/two/three» — одна карточка с цифрой по центру внизу, потом 3 карточки перестраиваются (2-1-3). |
| G2 | **Карточка-пример (видео в рамке)** | Пример/вставка в вертикальной карточке ~65% ширины поверх размытого и затемнённого основного кадра; белая рамка со свечением, уголки-скобки. |
| G3 | **Плашка с цифрой просмотров/результата** | Капсула с тёмным стеклом, зелёная иконка-глаз + зелёная цифра («500K», «2.5M») под карточкой. Для нас — результат/сумма/срок в капсуле. |
| G4 | **Стопка крупного текста** | 3–4 строки огромного жирного текста (белый + одно слово жёлтым/оранжевым) внутри карточки: «DON'T / POST / ANOTHER / VIDEO». |
| G5 | **Рукописное слово + жирное** | Тонкое рукописное (script) слово «before» рядом с жирным «DOING» — контраст шрифтов. |
| G6 | **Цветной светящийся заголовок** | Название приёма неоновым цветом со свечением (голубой «PATTERN INTERRUPT», красный «ZERO SENSE», зелёный «EXPLAIN IT», жёлтый «“YOU”»). Цвет = смысл: красный — ошибка/плохо, зелёный — правильно, жёлтый/оранжевый — акцент. Для нас — оранжевый/синий бренда + красный/зелёный для «źle/dobrze». |
| G7 | **Акцентное слово в кавычках** | Маленькое белое «say» сверху + крупное жёлтое «“YOU”» со свечением + маленькое «before / anything else» снизу. |
| G8 | **Скрин интерфейса** | Скриншот приложения/экрана (график удержания, таймлайн) в карточке; на нём курсор/рука, цифра на экране «перещёлкивается» (90,235 → 428). |
| G9 | **Счётчик** | Крупные цифры, которые набегают: таймер 23:59:58 → 24:00:00, проценты 72% → 100%, номер «01-02-03». |
| G10 | **Иконка «Сохрани»** | Большая белая иконка закладки по центру на «save this» — пульсирует. |
| G11 | **Призыв двумя цветами** | «FOLLOW ME» голубым со свечением + «FOR MORE» белым крупно. Для нас: «ZAOBSERWUJ» оранжевым + «PO WIĘCEJ» белым. |
| G12 | **Плашка-метка** | Тёмная плашка «EDITED 100% WITH» + оранжевая «CLAUDE CODE» сверху кадра; маленькая метка «EFFECTS APPLIED» + крупный номер «03». |
| G13 | **Слово-плашка в субтитрах** | Одно слово в субтитре на оранжевой плашке («the **colour**»). |

## Субтитры в референсе
- По одному-двум словам, белые жирные, внизу груди; ключевые слова — цветом со свечением (см. G6/G7). Совпадает с нашим стилем; цветные акценты — добавить для 1–2 ключевых слов на ролик.

## Переходы
| Код | Переход | Где |
|---|---|---|
| P1 | **Белая вспышка** (кадр «выбеливается» на 2–4 кадра) | смена темы, переход к следующему пункту списка |
| P2 | **Размытие фона + карточка выезжает** | переход к примеру (G2): фон размывается и темнеет, карточка «вылетает» с масштабом |
| P3 | **Перестройка карточек** | карточки 1-2-3 меняются местами |
| P4 | **Конечная заставка платформы** | тёмный фон + логотип — не используем (это экран TikTok) |

## Звук
Каждое появление карточки/заголовка/цифры — whoosh/pop; счётчик — тиканье/щелчки. Музыку из референса не брать.
