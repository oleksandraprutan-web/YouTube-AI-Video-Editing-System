# Профиль: персональный тренер

Дополняет общую основу `../SKILL.md`.

## Кто в кадре
Один тренер-мужчина (длинные кудрявые волосы, футболка хаки). Съёмка в студии: силовая рама GRAND, блочный тренажёр, доска с рисунками, белые стены. Форматы:
- говорящая голова (сидя/стоя, часто с микрофоном-петличкой в руке);
- демонстрация упражнения (тяга блока, присед, гиря) сбоку/спереди;
- B-roll (стоки или AI-картинки): люди, бытовые сцены, анатомия.

Язык — польский, обязательны корректные диакритики.

## Фирменные цвета
- **Яркий циан `#01FDF5`** — акценты: ключевые слова, плашки, стрелки, подсветка.
- **Тёмно-серый `#443F3C`** — подложки-полосы под белым текстом, текст на циановых плашках.
- Белый — основной текст субтитров.
- В прошлых роликах встречается приглушённый бирюзовый (~#2EC4B6 / мятный) — заменяем на фирменный `#01FDF5`.
- Красный — только для разметки «ошибка» (линии/точки на суставах, крестик); зелёный ✓ — «правильно».

## Субтитры (по прошлым роликам)
- Montserrat ExtraBold/Black, ЗАГЛАВНЫЕ, белые с лёгкой тенью, по 1–2 слова, по центру на уровне груди (~70–78% высоты).
- **Ключевое слово — циановым** (`#01FDF5`, без плашки, можно лёгкое свечение): «JEST **PRAWIDŁOWA**», «TWÓJ **PRZYSIAD**».
- Важная фраза целиком (2–4 строки) — циановым блоком по центру, на груди («TOBIE MOŻE BYĆ DUŻO TRUDNIEJ…»).

## Графика
1. **Хук-заголовок** — тёмная карточка `#443F3C` (или цитата клиента в кавычках «“» циан), текст печатается синхронно с речью, главное слово циан. Первые 1–3 с ролика. (Старые обложки с «рваными» полосами — НЕ эталон, автор просила ориентироваться только на видео.)
2. **Плашки-таблетки** — циановые скруглённые плашки с тёмным текстом ЗАГЛАВНЫМИ: заголовок списка сверху, пункты «1. …», «2. …» под ним; подписи к B-roll по центру кадра («NAKŁADKA TOALETOWA»).
3. **Чек-лист с галочками (из референса verse.fitness)** — заголовок + ряд пустых квадратов, по мере пунктов ставятся галочки; пункт — плашка «☑ 2. ROZGRZEWKA» сбоку от человека.
4. **Анатомическая разметка поверх упражнения** — подсветка рабочих мышц полупрозрачным цветом, линии суставов/углов (точка + линия, «przedramiona»), вертикаль траектории грифа, линия «бедро ниже колена», стрелки направления (носки наружу), круг-пунктир вокруг стопы. Разметка — белая/циановая; ошибка — красная.
5. **Зелёная галочка в круге** над головой на «prawidłowo / dobrze».
6. **Картинка-в-рамке** — кадр уменьшается в карточку на циановом фоне (`#01FDF5`) на акценте/цитате.
7. **Анатомия/скелет** — вставка на белом фоне с подсветкой суставов.
8. **Цветной фильтр** — тёплая/оранжевая тонировка кадра на «źle / błąd» (было в прошлых роликах; использовать редко).

## Монтаж
- Пожелание автора: **чёткий, минималистичный, но цепляющий**; любит разные анимации (шкалы, чек-листы, кнопки, перечёркивания) — по одной идее на смысловой блок, без перегруза.
- **Звук/музыку исходника не трогать** — оставлять как на видео (музыку сверху не класть, если автор не попросит).
- Динамичный: смена плана каждые 2–3 с, чередование говорящей головы и демонстрации упражнения; B-roll на смысловых словах (голос продолжается).
- Зумы — чередование общего/среднего плана, резкий наезд на хуке и на «błąd / źle».
- На демонстрации упражнения — допускается замедление (speed ramp) в ключевой фазе движения + разметка (п. 4).
- Переходы — быстрые (whip/зум-блюр), без длинных эффектов.

## Звук
- Музыка — энергичная, спортивная, ненавязчивая, под голосом −18…−22 дБ.
- SFX — **не «игровые»** (автору не нравятся синтетические pop/ding/buzz/sparkle/notify). Брать спокойные звуки из бесплатных паков GareBear99 (список: github.com/GareBear99/awesome-audio-plugins-dev → SAMPLE_PACKS_AND_SOUND_RESOURCES.md; Free-Riser-Producer-Kit, Free-Future-Bass-Producer-Kit — free for commercial use, сырые сэмплы не распространять, в git не класть):
  - появление плашки/карточки/галочки — короткий closed hi-hat (тик), −28…−32 dB;
  - смена плана — Riser_Whoosh (кусок вокруг пика), выравнивать пиком на склейку;
  - акцент/«нет» — мягкий kick (thump) + тихий impact tail, вместо «ошибки»;
  - «правильный ответ», нажатие кнопки — короткий pluck;
  - растущая шкала — filtered sweep под длину анимации; вход в концовку — reverse cymbal, концом на склейку.
- Исходный звук (голос + музыка автора) не трогать.

## Концовка
- Призыв «ZAOBSERWUJ» / «ZAPISZ» — циановая плашка или стрелка, по согласованию с автором.
