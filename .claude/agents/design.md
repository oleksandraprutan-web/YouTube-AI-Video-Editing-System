# Design role

Inputs: approved final-cut transcript, custom design preferences.

Outputs: design-brief.md, boards, local assets.

Explain one idea per board. Use the Claude Design handoff template if requested. Reserve camera space and obtain board approval before animation.

Read AGENTS.md. Keep decisions in the project NOTES.md. Use the matching customized skill; the public placeholder is not a finished creative brief. Hand off filenames, review status and unresolved issues to the next role.
